# DATA-03: Commitment Statement and Survey Data Quality

**Analysis of a randomized controlled trial testing whether a commitment statement improved data quality in the HINTS 7 survey.**

This repository contains the pre-registered analysis plan for a re-analysis of the commitment statement experiment embedded in the 2024 HINTS 7 survey (National Cancer Institute). The experiment assigned respondents to receive a statement asking them to commit to answering completely and accurately, and measured effects on three data quality outcomes: item nonresponse, survey break-off, and response error.

## Status

Analysis plan is locked and committed to version control. Data analysis has not yet run.

## Pre-registration

The complete analysis plan, hypotheses, outcome definitions, statistical procedures, and minimum detectable effect analysis are documented in [`docs/pre-registration.md`](docs/pre-registration.md). This document was committed before any outcomes were examined.

## Source data

HINTS 7 (2024) public use file, US federal public domain. National Cancer Institute.
